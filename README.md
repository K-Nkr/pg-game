# 🍲 麻辣湯 1,000円ピッタリ選手権 (1g＝4円)

麻辣湯（マーラータン）の実店舗さながらに、具材を選んでボウルに盛り付け、**1g＝4円でピッタリ1,000円（250.0g）**を目指すトッピング計量ブラウザゲームです！

---

## 🎮 ゲームの特徴

- **本物そっくりの量り売りシステム（1g＝4円）**:
  - 実店舗の料金体系を忠実に再現！
  - 目標は **1,000円（＝250.0g）**！
  - 具材の重さは隠しパラメータ！見た目のサイズ感と料理の勘を研ぎ澄まして挑戦。
- **リアルな具材ビジュアル**:
  - 茹でたてツヤツヤの「特太タンミョン（寛粉）」や「中華ちぢれ麺」、青梗菜、厚切りスパム、大粒エビ、うずら卵など19種類のトッピング。
- **自由自在なトッピング＆レイアウト機能**:
  - 丼（ボウル）の中へドラッグ＆ドロップで自由に配置可能。
  - タップで45度ずつ回転、**✨キラキラ＆最前面バウンス演出**、削除も自由自在。
- **電子レジはかりのリアルタイムカウントアップ**:
  - 「お会計する！」を押すと、重さ（g）と金額（円）がリアルタイムにパラパラとカウントアップ！
  - ピッタリ1,000円ジャストなら紙吹雪が舞う最高ランク『SSS 神会計麻辣湯仙人』認定！
  - お店風のトッピング明細レシート＆X（Twitter）シェア機能搭載。
