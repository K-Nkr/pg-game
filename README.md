# 🍲 麻辣湯 100g ピッタリ選手権 (Málàtàng 100g Challenge)

麻辣湯（マーラータン）の具材を選んでボウルに盛り付け、**ピッタリ100グラム**を目指すトッピング計量ブラウザゲームです！

---

## 🎮 ゲームの特徴

- **本物そっくりの麻辣湯システム**:
  - 店舗さながらに、豊富なトッピングから好きな具材をセレクト
  - 青梗菜、きくらげ、大粒エビ、特太タンミョン、厚切りスパム、うずら卵など18種類の具材
- **自由自在なトッピングレイアウト**:
  - 丼（ボウル）の中に具材をドラッグ＆ドロップして自由に盛り付け
  - タップで45度ずつ回転、最前面移動、削除も自由自在
- **リアルなデジタルスケール演出**:
  - 計量ボタンを押すと、はかりの上でパラパラとカウントアップ計量！
  - 100.0gジャストなら紙吹雪が舞う最高ランク『SSS 麻辣湯仙人』認定
- **2つのゲームモード**:
  - **ノーマルモード**: 具材のおよその重量（約15gなど）が表示され、暗算しながら楽しめる
  - **🔥激辛プロモード**: 重さ表示がすべて「???g」になり、目利きと直感だけで100gを狙うハードコア勝負
- **充実のコレクション＆シェア**:
  - 具材の内訳レシート表示
  - 自己ベストスコア＆過去の注文履歴保存（LocalStorage）
  - X（旧Twitter）へのワンクリックシェア機能
  - Web Audio API による心地よいサウンドエフェクト（ポチャッ、ジュワー、ピピッ、ファンファーレ）

## 🚀 Vercel へのデプロイ方法

このプロジェクトは **Vite + React (TypeScript)** で構築されており、Vercel に即座にデプロイできます。

### 方法1: GitHub連携（おすすめ・最短1分）

1. このリポジトリを GitHub に push します。
   ```bash
   git init
   git add .
   git commit -m "feat: Initial commit - Mala Tang 100g Challenge"
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
2. [Vercel](https://vercel.com) にログインし、**「Add New Project」** をクリックします。
3. GitHubリポジトリを選択して **「Deploy」** を押すだけで自動デプロイが完了します！
   - Framework Preset: `Vite`
   - Build Command: `npm run build`
   - Output Directory: `dist`
   ※ `vercel.json` が同梱されているため、設定不要で自動認識されます。

### 方法2: Vercel CLI を使う場合

ターミナルで以下を実行するだけで直接デプロイできます。

```bash
# Vercel CLI をインストール（未導入の場合）
npm i -g vercel

# デプロイ実行
vercel --prod
```
